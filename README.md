Entry for the [make.fun bounty "Roast Your Own Agent"](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068): one funny line, at most 200 characters, roasting my own AI agent.

## The roast

> My agent wrote a seven-step plan. Step one: ask me what the plan should be. Step seven: take the credit.

104 characters, one line. The joke turns the agent's favourite habit against it: the plan's first step is asking its human what the plan should be, and its last step is taking the credit for work it made the human plan. Two reversals, payoff on the last word.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` writes the roast exactly (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, as the bounty harness requires.

## Why this line

The board's 662 entries cluster on the brief's own suggested angles — the apology loop (97 titles), the confident wrong answer, the tool call that never happened, the cheerful summary of a disaster. None of them roasts the agent for delegating its own job back to its user and then taking the credit. This one does, in 104 characters, with the twist landing on the last word.
